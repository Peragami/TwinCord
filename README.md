# TwinCord

2アカウント同時常駐の軽量Discordラッパー (Windows / C# + WebView2)

公式デスクトップ版を2つ起動すると重いため、OS共有のWebView2ランタイム上に
Discord公式Web版を2枚埋め込み、1プロセスで2アカウントを同時利用します。

## 機能

- Discord風の左レールで2アカウントを切替(両方常駐、通知ソケット維持)
- レールにDiscordアバター表示、ダブルクリック/右クリックで改名
- 非表示側の未読バッジ、メンション等のバルーン通知(クリックで該当アカへ移動)
- 通知履歴(トレイメニューから表示)
- トレイ常駐、二重起動時は先発ウィンドウを表示
- ページ内 `Ctrl+1/2` でアカウント切替
- アカ別ミュート、拡大率(50〜200%)、Windows自動開始
- 通話中はメモリ抑制・自動リロードを回避
- 自己診断(応答速度・メモリ・バッジ・アバター状態)と劣化通知
- 設定のエクスポート/インポート
- 省メモリ: 非表示側ヒープ抑制、最小化時のワーキングセット返却、手動再読み込み

## 必要環境

- Windows 10 / 11 (WebView2 ランタイム標準搭載)
- .NET 10 SDK (ビルド時) / .NET 10 ランタイム (フレームワーク依存版の実行時)

## ビルド

```powershell
dotnet build -c Release
```

## 配布物作成

```bat
publish.bat                 :: フレームワーク依存の単一exe (publish\TwinCord.exe, .NET 10必須)
publish-selfcontained.bat   :: ランタイム同梱の単一exe (publish-selfcontained\TwinCord.exe, 約200MB)
```

## 注意

- 表示しているのはDiscord公式Web版そのもので、トークンの抜き出しや
  非公開APIの直接利用、自動操作機能はありません。
- ただし100%の安全保証はできません。規約上は公式クライアントの利用が
  前提のため、利用は自己責任でお願いします。
- Discord側の更新で一部機能(未読バッジ等)が動かなくなる場合があります。
  その際は設定→アプリについて→自己診断で確認してください。

## バージョニング方針(厳密SemVer)

- パッチ(x.y.Z): 不具合修正・内部改善・文言変更。動作仕様は不変
- マイナー(x.Y.0): 機能追加(後方互換あり)
- メジャー(X.0.0): 破壊的変更(設定形式の非互換変更等)のみ

公開済みの番号は下げません。2.0は破壊的変更があるときだけです。
