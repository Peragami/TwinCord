# データの保存場所と削除

TwinCord はポータブル形式です。設定・通知履歴・ログ・アバター・Discord のログイン情報は、すべて **アプリのフォルダ内の `data\`** に保存します。`%LOCALAPPDATA%` などアプリ外の場所は使いません。

## data フォルダの中身

| パス | 内容 |
| --- | --- |
| `settings.json` | 設定 |
| `settings.json.bak` | 壊れた設定の退避(必要なときだけ作成) |
| `notifications.json` | 通知履歴 |
| `diagnostics.log` | 診断ログ(動作がおかしいときの調査用) |
| `avatars\` | レールに表示するアバター画像 |
| `webview2\` | Discord のログイン情報とキャッシュ(サイズが大きくなります) |

## バックアップ

- 設定だけを残す場合は、設定画面の「エクスポート」を使います。
- すべてを残す場合は、TwinCord を終了して `data\` フォルダごとコピーします。
- `webview2\` はサイズが大きいため、設定だけならエクスポートが軽量です。

## 削除(アンインストール)

1. 設定で「Windows 起動時に自動開始」をオフにする(オンにしていた場合)
2. TwinCord を終了して数秒待つ(WebView2 の子プロセスが残っていると削除に失敗します)
3. アプリのフォルダを丸ごと削除する

`data\webview2\` はログイン情報とキャッシュでサイズが大きくなりますが、フォルダごと消せば残りません。

## 書き込み権限

`Program Files` など書き込みできない場所に置くと起動できません(データを隣に保存するため)。デスクトップやドキュメントなど、ユーザーが書き込める場所へ置いてください。

## 旧バージョンからの移行

1.10.x までのデータは `%LOCALAPPDATA%\TwinCord` にあります。1.11.0 以降の初回起動時に引き継ぎを確認します。

- 「はい」を選ぶと新しい `data\` へ移動します。移動できない場合はコピーして元を残します。
- 「いいえ」を選ぶと新規状態で始まります。
- 旧方式の `acc1` / `acc2` フォルダは、現在の共有方式では使用しません。削除しても構いません。

## 更新時の注意

アプリの自動更新は `data\` と `mods\` を除いてアプリ本体をミラー同期します。アプリのフォルダに私物のファイルを置くと更新で消えるため、追加物は `data\` か `mods\` へ置いてください。
