# アカウント安全性

TwinCord は Discord 公式 Web 版を WebView2 で表示する非公式ツールです。コード全体を確認したうえでの整理です。

## 行っていないこと

- トークンの抜き出し
- 非公開 API の直接利用
- メッセージの自動送信・自動操作
- マクロ・スパム行為

## 外部通信

外部通信は次の3つだけです。

- Discord 本体
- Discord CDN(アバター画像)
- GitHub(更新確認と更新ファイルの取得)

更新ファイルは GitHub の当該リポジトリからのみ取得し、SHA256 を必須で検証してから入れ替えます。SHA256 が取得できない場合は自動更新を行いません。

## ページ側の処理

ページ側で行っているのは受動的な処理のみです。

- 通知の受け取り
- 未読バッジ等の読み取り
- キー操作の検出
- ダウンロードボタンの非表示化

ブラウザの正体は通常の Edge(WebView2)として見えるため、一般的な広告ブロッカー等と同程度の見え方です。BAN の検出対象になるような自動化・マクロ・スパム行為は搭載も想定もしていません。

## 注意

- 100% の安全保証はできません。Discord の規約上、公式クライアントの利用が前提のため、利用は自己責任でお願いします。
- 特に自動化ツールやマクロとの併用は避けてください。
- Discord 側の更新で一部機能(未読バッジ等)が動かなくなる場合があります。その際は設定 → アプリについて → 自己診断で確認してください。
