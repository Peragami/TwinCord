# 機能と使い方

TwinCord は Discord 公式 Web 版を WebView2 に2枚埋め込み、1つのアプリで2アカウントを同時に使う Windows 用ツールです。このページでは日常操作と機能の詳細をまとめています。

## アカウントと画面

- 左レールのアバターをクリックするとアカウントを切り替えます。非表示側も常駐し、通知ソケットは維持されます。
- アバターをダブルクリック、または右クリック →「名前の変更」で表示名を変更できます(最大24文字)。
- 非表示側の未読はレールのバッジに表示されます。メンションなどはバルーン通知で知らせます。
- 通知をクリックすると、該当するアカウントへ移動します。
- 右クリックメニューからアカウント別にミュートできます。状態は保存されます。
- 拡大率はアカウントごとに 50〜200% の範囲で 5% 刻みに設定できます。
- ウィンドウの位置・サイズ・最大化状態は保存されます。画面外に出た場合は復帰します。

## 通知

- 設定 →「TwinCord の通知」で通知全体を ON/OFF できます。
- 「表示中のアカウントの通知は出さない」で、いま見ているアカウントの通知を抑制できます。
- 「最小化・トレイ格納中のみ通知する」で、作業中の割り込みを減らせます。
- 通知履歴はトレイメニューから表示できます。
- Discord 側のサーバー・チャンネル別の通知設定は Discord 本体で行ってください。TwinCord はアプリが出す通知全体を制御します。
- 同じ通知の二重表示を防ぐため、通知の経路ごとに判定しています。

## キーボード操作

| キー | 動作 |
| --- | --- |
| `Ctrl+1` / `Ctrl+2` | Discord ページ内でアカウントを切替 |
| `Ctrl+Alt+1` / `Ctrl+Alt+2` | 他のアプリが前面にあってもアカウントを切替 |
| `Ctrl+Alt+M` | 表示中のアカウントのミュートを切替 |

グローバルホットキーは、他のアプリが同じキーを使っていると登録に失敗することがあります。その場合は自己診断に表示されます。

## 省メモリ・省CPU

- 2アカウントで WebView2 のブラウザ/GPU プロセスを共有し、ログイン情報だけをプロファイルで分離しています。
- 非表示側やトレイ格納中はヒープを抑制し、最小化時にはワーキングセットを返却します。
- バッジ・未読・通話の確認を1回のスクリプト実行にまとめ、変化がないときは確認間隔を自動で延長します。
- 通話中はメモリ抑制と自動リロードを回避します(プロセス異常時の復旧を除く)。
- 起動時は表示中のアカウントを先に読み込み、2枚目は1枚目の表示完了後に初期化します。
- 状態が重くなった場合は、手動の再読み込みでメモリを戻せます。

## 自己診断

- 設定 → アプリについて → 自己診断で、応答速度・メモリ・バッジ・アバター状態を確認できます。
- 動作の劣化を検知すると通知します。診断結果はコピーできます。
- Discord 側の更新で一部機能が動かなくなった場合は、まず自己診断を確認してください。

## 設定

- 変更は「保存」で確定します。エクスポート/インポートにも対応し、インポートも「保存」で確定します。
- 「ダウンロードボタンを隠す」は再起動なしで反映されます。
- リンクにマウスを乗せたときの URL 表示を抑制できます。
- 設定・履歴・更新ダイアログは Discord 風のダーク UI です。
- 設定ファイルが壊れている場合は `data\settings.json.bak` に退避してから保存します。

## 自動更新

- 起動時に更新を確認します(設定でオフにできます)。GitHub Releases の最新版を取得します。
- 更新は `TwinCord.zip` をダウンロードし、SHA256 を検証してから適用します。
- `data\` と `mods\` は更新後も保持されます。
- 失敗時は元のファイルへ戻して再起動し、理由を `update-error.log` に記録します。

詳しい仕組みは [ビルドとリリース](build.md) を参照してください。

## その他

- トレイに常駐します。二重起動した場合は、先に起動しているウィンドウを表示します。
- Windows 起動時の自動開始と、起動時の最小化に対応しています。
- 設定・ログイン情報・履歴はアプリのフォルダ内の `data\` に保存します。詳しくは [データの保存場所と削除](data.md) を参照してください。
